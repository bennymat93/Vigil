Vigil

Keeps your PC awake and unlocked

What Vigil does

Vigil sits in the system tray (next to the clock) and stops Windows from locking or turning off the screen while you are away — for example during a long video. It is built to withstand strict corporate lock policy, using only standard Windows APIs.

Using the tray icon

Toggle keep-awake on / off. The icon switches between the open eye (active) and the closed eye (paused).

How it works

A corporate forced lock is driven by the input idle timer. Vigil combines two layers: it calls SetThreadExecutionState (prevents sleep / display-off) and sends a tiny, harmless F15 key pulse every ~50 seconds, which resets the idle timer and defeats the forced lock — all with standard, documented Windows APIs, no admin rights and no network.

  2. למנוע גם כיבוי מסך, לא רק נעילה.

  7. הפעלה אוטומטית עם Windows (למשתמש הנוכחי, ללא מנהל).

איך זה עובד

נעילה כפויה נקבעת לפי מד חוסר הפעילות של הקלט. Vigil משלב שתי שכבות: קריאה ל-SetThreadExecutionState (מונעת שינה וכיבוי מסך) ושליחת פעימת F15 תמימה כל כ-50 שניות, שמאפסת את מד חוסר הפעילות ומונעת את הנעילה — הכול בממשקי Windows מתועדים, ללא הרשאות מנהל וללא רשת.
